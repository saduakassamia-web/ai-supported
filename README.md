# AI-Supported Assessment Platform 🤖📐

An interactive, responsive web-based platform built to showcase how Artificial Intelligence (AI) can be utilized for digital assessment and formative feedback in education.

## Assignment Overview & Structure 📋

This platform is structured into core sections to meet educational technology assessment criteria:

### Section 1: AI for Assessment
- **Digital Quiz:** Features a 10-question mathematics assessment generated via Gemini AI covering arithmetic, equations, geometry, and quadratics with varying difficulty levels (easy, medium, hard).
- **Interactive Experience:** Real-time options tracking, instant answer verification, progress bar, and score summaries.
- **Answer Key:** Dedicated section providing detailed step-by-step solutions and formulas.

### Section 2: AI-Supported Feedback
- **Student Samples:** Analyzes 3 distinct student performance samples (strong, average/calculation error, and weak/conceptual misconception) for a linear equation problem.
- **Critical Review:** Compares raw AI-generated feedback against the teacher's pedagogical improvements (adjusting tone, adding scaffolding hints, and reinforcing checking habits).

### Prompts & Critical Reflection
- **AI Prompts:** Complete transparency on the exact prompts provided to generate the quiz and feedback.
- **Pedagogical Reflection:** A 100–150 word critical reflection evaluating AI's time-saving benefits versus its limitations in pedagogical empathy and contextual nuance.

## Built With 🛠️
- **HTML5 & JavaScript** - Core interactive logic and single-page routing
- **Tailwind CSS** - Modern utility-first styling and dark/light mode
- **MathJax** - Professional LaTeX mathematical expression rendering
- **FontAwesome** - UI icons
